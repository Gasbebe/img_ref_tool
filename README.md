# img-ref-tool

Windows와 macOS에서 동작하는 이미지 레퍼런스 보드의 초기 프로토타입입니다.

## 실행

```text
cargo run
```

## 현재 조작

- 이미지 파일을 창에 드롭: 보드에 이미지 추가
- 왼쪽 클릭: 이미지 선택 (겹친 곳에서는 가장 위 이미지), 빈 곳 클릭: 선택 해제
- `Q`: 이동 도구 — 왼쪽 드래그로 이미지 이동
- `W`: 회전 도구 — 왼쪽 버튼을 누른 채 좌우 드래그로 이미지 중심 기준 회전
- `E`: 스케일 도구 — 왼쪽 버튼을 누른 채 좌우 드래그로 중심과 가로세로 비율을 유지하며 크기 조절
- 왼쪽 위 도구 버튼으로도 전환 가능. 조작 중에는 도구 전환과 카메라 이동/줌을 잠시 고정
- 마우스 휠: 커서 위치를 중심으로 확대/축소
- 마우스 가운데 또는 오른쪽 버튼 드래그: 캔버스 이동
- `0`: 카메라 초기화

## 프로젝트와 메모

- Save 또는 Ctrl+S / Cmd+S: 첫 저장에서 프로젝트 폴더를 선택합니다. 이후 자동 저장(약 3초 간격, 조작·메모 편집 종료 후)됩니다.
- Open 또는 Ctrl+O / Cmd+O: 프로젝트 폴더를 선택하면 그 안의 `project.json`을 엽니다. 실패하면 현재 보드를 유지합니다.
- 프로젝트 폴더에는 `project.json`, `assets/`, `cache/`가 있습니다. 폴더 전체를 옮기면 다른 컴퓨터에서도 원본 경로 없이 열립니다.
- 이미지 원본 파일의 바이트를 포함 저장합니다. 동일 내용은 SHA-256 해시로 중복 저장하지 않습니다.
- 저장 파일은 임시 파일을 기록·동기화한 뒤 교체합니다. 이전 JSON은 `project.backup.json`에 보관합니다. 백업 복구 UI는 이후 단계에서 추가합니다.
- Add Note 버튼 또는 캔버스 우클릭 → Add Note. 더블클릭하면 본문·글자 크기·색·박스 크기를 편집합니다. Done으로 종료합니다.
- 메모도 Q/W/E로 이동·회전·스케일합니다. Width 변경은 줄바꿈을 조절하며, E는 글자까지 함께 확대합니다.
- Undo / Redo 버튼 또는 Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z를 사용합니다. Windows에서는 Ctrl+Y로도 Redo할 수 있습니다. 이미지 드롭, 메모 추가·편집, Q/W/E 드래그를 최대 200단계 기록하며 프로젝트를 열면 기록을 초기화합니다.
- 한글은 Windows 맑은 고딕 / macOS Apple SD Gothic Neo 시스템 폰트를 사용합니다. 두 OS에서 글꼴 차이로 줄바꿈이 달라질 수 있습니다.
- 프로젝트에 항목 ID, 중심 좌표, 크기, 회전, 순서, 메모 UTF-8 본문·스타일, 카메라 중심·줌을 저장합니다.

현재 GPU 미리보기는 최대 1,024px입니다. 원본은 축소하지 않고 보존하며, 저장 시 `cache/previews/`에 바로 읽을 수 있는 미리보기를 만듭니다. 이전 버전의 2,048px 캐시는 처음 한 번 축소해 교체하고 다음 로드부터 사용합니다. 상태 표시에는 파일 선택 시간을 제외한 실제 프로젝트 로드 시간이 표시됩니다. 비동기 로딩, 확대 시 고해상도 교체와 CPU/GPU 캐시 예산은 아직 구현되지 않았습니다.
